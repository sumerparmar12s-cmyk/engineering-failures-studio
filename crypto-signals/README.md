# Crypto Signal System (शिक्षा के लिए)

यह सिस्टम असली मार्केट डेटा देखकर BUY / SELL / इंतज़ार का सिग्नल देता है — एंट्री, स्टॉप-लॉस और टारगेट के साथ।
साथ ही वही नियम पिछले ~500 दिनों के डेटा पर टेस्ट करके दिखाता है कि **असल में** कितनी बार जीत हुई।

> ⚠️ यह निवेश सलाह नहीं है। कोई भी स्ट्रेटजी पक्की नहीं होती। हर ट्रेड में अपनी कुल पूंजी का **1% से ज़्यादा रिस्क न लें**।

## चलाना कैसे है

1. Python 3.10+ इंस्टॉल करें (python.org से)।
2. टर्मिनल में:
   ```
   pip install pandas numpy requests
   python signals.py
   ```
3. बनी हुई `report.html` फ़ाइल ब्राउज़र में खोलें।

और विकल्प:
```
python signals.py --interval 1d                  # डेली चार्ट
python signals.py --symbols BTCUSDT DOGEUSDT     # अपनी पसंद के कॉइन
python signals.py --loop 15                      # हर 15 मिनट में दोबारा जाँच + अलर्ट
```

## फ़ोन पर अलर्ट (Telegram)

1. Telegram में **@BotFather** खोलें → `/newbot` → जो **token** मिले वो कॉपी करें।
2. अपने नए बॉट को कोई भी मैसेज भेजें, फिर ब्राउज़र में खोलें:
   `https://api.telegram.org/bot<TOKEN>/getUpdates` → उसमें `"chat":{"id": ...}` वाला नंबर आपका **chat id** है।
3. चलाएँ:
   ```
   # Windows (PowerShell)
   $env:TELEGRAM_BOT_TOKEN="..."; $env:TELEGRAM_CHAT_ID="..."; python signals.py --loop 15
   # Mac / Linux
   TELEGRAM_BOT_TOKEN=... TELEGRAM_CHAT_ID=... python signals.py --loop 15
   ```
   नया सिग्नल बनते ही फ़ोन पर मैसेज आएगा। (कंप्यूटर चालू रहना चाहिए।)

## सिस्टम क्या-क्या देखता है

| चीज़ | मतलब |
|---|---|
| **ट्रेंड** (EMA 50/200) | प्राइस 200 EMA के ऊपर और 50 > 200 = तेज़ी, उल्टा = मंदी। सिस्टम ट्रेंड के **ख़िलाफ़ ट्रेड नहीं** लेता। |
| **सपोर्ट / रेज़िस्टेंस** | पिछले स्विंग हाई/लो, जहाँ प्राइस बार-बार रुका (`×2` = दो बार टच हुआ)। |
| **वॉल्यूम** | पिछले 20 कैंडल के औसत से 1.5 गुना ज़्यादा = असली ख़रीद/बिक्री का दबाव। |
| **RSI** | 70+ = बहुत ज़्यादा ख़रीदा जा चुका, 30- = बहुत ज़्यादा बिका हुआ। |
| **कैंडलस्टिक पैटर्न** | Bullish/Bearish Engulfing, Hammer, Shooting Star, Morning/Evening Star, Doji। |
| **ATR** | औसत उतार-चढ़ाव — स्टॉप-लॉस इतना दूर रखा जाता है कि नॉर्मल हिलने में न कटे। |

### 4 सेटअप
1. **Breakout BUY** – तेज़ी में, कैंडल रेज़िस्टेंस के ऊपर बंद + वॉल्यूम स्पाइक।
2. **Breakdown SELL** – मंदी में, कैंडल सपोर्ट के नीचे बंद + वॉल्यूम स्पाइक।
3. **Pullback BUY** – तेज़ी में प्राइस 50 EMA/सपोर्ट तक गिरे और bullish पैटर्न बने।
4. **Pullback SELL** – मंदी में प्राइस 50 EMA/रेज़िस्टेंस तक चढ़े और bearish पैटर्न बने।

**स्टॉप-लॉस:** सिग्नल कैंडल/लेवल के पार या कम से कम 1.5×ATR दूर।
**टारगेट:** T1 = रिस्क का 1.5 गुना, T2 = 3 गुना। (T1 पर आधा बेचें, बाकी का SL एंट्री पर ले आएँ।)

## नतीजे कैसे पढ़ें
- **R** = एक ट्रेड का रिस्क। +1.5R मतलब जितना रिस्क लिया उसका डेढ़ गुना कमाया; −1R मतलब SL लगा।
- **जीत 40%** भी ठीक हो सकती है अगर औसत R पॉज़िटिव है (जीत बड़ी, हार छोटी)।
- **Max drawdown** = लगातार हार में सबसे बड़ी गिरावट। 10R का मतलब है 1% रिस्क पर पूंजी ~10% नीचे।
- बैकटेस्ट में 0.1% फीस दोनों तरफ़ जोड़ी गई है। भारत में मुनाफ़े पर 30% टैक्स + 1% TDS अलग से है।

## SELL का मतलब
स्पॉट (सामान्य ख़रीद) में SELL = पहले से ख़रीदा है तो बेच दें / नया न ख़रीदें।
फ़्यूचर्स में शॉर्ट करना ज़्यादा जोखिम वाला है — शुरुआत में न करें।
