# Google Flow — Deepwater Horizon क्लिप्स

## कैसे करें (फ़ोन पर)
1. Chrome में खोलें: labs.google/flow (Pro वाले Gmail से लॉगिन)
2. New project → Text to Video → Landscape 16:9 → मॉडल: Veo Fast (कम क्रेडिट)
3. नीचे से एक prompt पूरा कॉपी करें → पेस्ट करें → बनाएँ
4. जो वीडियो सबसे अच्छा लगे उसे डाउनलोड करें (1080p)
5. फ़ाइल का नाम नंबर रखें (जैसे 01.mp4) और इस चैट में भेजें
6. पहला Gmail के क्रेडिट खत्म हों तो दूसरे Gmail से बाकी बनाएँ

⭐ = सबसे ज़रूरी (पहले ये बनाएँ)। अगर क्रेडिट कम हों तो सिर्फ़ ⭐ वाले भी काफ़ी हैं।
